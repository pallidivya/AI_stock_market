# 📈 AI Stock Market Research Company

An AI-powered multi-agent stock market research system that analyzes stocks from multiple perspectives and generates a comprehensive investment research report.

The system uses specialized AI agents for **News Analysis, Financial Analysis, Technical Analysis, Risk Analysis, Portfolio Management, Investment Advice, and Daily Report Generation**.

---

## 🚀 Features

### 📰 News Analysis

Analyzes recent stock-related news and provides:

* News summary
* Market sentiment
* Important events
* News impact
* Risk factors
* Recommendation

### 📄 Financial Analysis

Analyzes a company's annual financial report PDF and provides:

* Revenue analysis
* Profitability
* Balance sheet analysis
* Cash flow analysis
* Financial risk
* Growth outlook
* Investment recommendation

### 📈 Technical Analysis

Analyzes stock market data using technical indicators such as:

* Moving averages
* RSI
* MACD
* Trading volume
* Overall trend
* Buy / Hold / Sell signal

### ⚠️ Risk Analysis

Evaluates stock risk using:

* Annualized volatility
* Maximum drawdown
* Sharpe ratio
* Risk level
* Risk score
* Investment suitability
* Recommendation

### 💼 Portfolio Management

Analyzes multiple stocks and provides:

* Portfolio summary
* Diversification analysis
* Overall portfolio risk
* Strongest stock
* Weakest stock
* Suggested allocation percentages
* Portfolio recommendation

### 💡 Investment Advisor

Combines the results from:

* News Agent
* Financial Agent
* Technical Agent
* Risk Agent

and generates:

* Final investment rating
* Confidence score
* Final recommendation
* Overall explanation

### 📑 Daily Research Report

Combines all analyses and generates a professional research report containing:

* Executive Summary
* News Analysis
* Financial Analysis
* Technical Analysis
* Risk Analysis
* Final Investment Recommendation
* Confidence Score
* Conclusion

```text
             │

             │
             ▼

```

## 🎯 Project Objective

The main objective of this project is to build an AI-powered stock research assistant that can automate multiple stages of equity research.

Instead of manually analyzing news, financial reports, technical indicators, and risk metrics separately, the system uses specialized AI agents and combines their outputs into a single research report.
